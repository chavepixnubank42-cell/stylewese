# STYLEWISE — Fashion AI Personal Stylist

## Overview
Premium fashion AI personal stylist web app with digital wardrobe management, AI-powered look analysis, outfit generation, trend tracking, and personalized style learning.

## Design System
- **Palette**: #111111 (black), #F7F5F2 (off-white bg), #C8A96B (champagne accent), #171717 (text), #77736D (secondary text), #FFFFFF (cards)
- **Fonts**: Playfair Display (headings) + Inter (body) via Google Fonts
- **Style**: Magazine-like, luxury fashion aesthetic, mobile-first
- **Animations**: Framer Motion throughout

## Tech Stack
- Auth: NextAuth v5, email/password, JWT strategy
- DB: PostgreSQL + Prisma ORM
- Storage: S3 (presigned URLs for upload, signed URLs for private access)
- AI: Abacus.AI LLM APIs (vision for wardrobe analysis, text for outfit generation)
- Charts: Recharts (trend evolution chart on Radar page)

## Architecture
- Route group `(app)` for authenticated pages with bottom nav shell
- Bottom nav: Home, Wardrobe, Create (floating submenu: Analyze/Outfit/Occasion), Radar, Favorites
- Profile accessible from Home page header
- Radar page uses dark background (`.dark-section` CSS class)
- All API routes auth-guarded with `auth()` from `@/auth`
- Streaming responses for AI features (analyze-look, generate-outfits)

## Key Patterns
- Wardrobe upload: presigned URL → S3 → AI vision analysis → save metadata
- Look analysis: upload photo → streaming AI score + feedback
- Outfit generation: select items/occasion → streaming AI suggestions → rate/fav
- Favorites: toggle system via POST /api/favorites
- Ratings: 👍/👎 via POST /api/ratings (upsert)
- Trends: demo data seeded, structured for future real API integration
